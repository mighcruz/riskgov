# Dados do Simulador — RiskGov

## 1. Objetivo

Este diretório é destinado à documentação e à organização dos dados utilizados ou previstos para o simulador RiskGov.

Os dados poderão representar informações necessárias para a definição dos cenários, situações de risco, decisões, consequências e resultados.

Neste momento, este diretório possui finalidade principalmente documental e estrutural. A presença deste diretório não implica, isoladamente, a existência de uma base de dados operacional ou de um mecanismo automatizado de persistência.

---
