# Dados do Simulador — RiskGov

## 1. Objetivo

Este diretório é destinado aos dados utilizados pelo simulador RiskGov.

Os dados poderão representar informações necessárias para a definição dos cenários, situações de risco, decisões, consequências e resultados.

---

## 2. Estrutura Conceitual

Os dados de um cenário poderão ser organizados conceitualmente da seguinte forma:

```text
Cenário
   ↓
Contexto
   ↓
Situação
   ↓
Informações
   ↓
Opções de Decisão
   ↓
Consequências
   ↓
Resultado
