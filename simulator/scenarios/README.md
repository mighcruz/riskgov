# Cenários de Simulação — RiskGov

## 1. Objetivo

Este diretório é destinado à documentação dos cenários utilizados ou previstos para o simulador RiskGov.

Os cenários representam situações de risco utilizadas para exercícios de análise, tomada de decisão e avaliação das consequências das ações escolhidas pelo participante.

---

## 2. Estrutura Conceitual

Cada cenário poderá ser estruturado considerando:

```text
Contexto
   ↓
Situação de Risco
   ↓
Informações Disponíveis
   ↓
Decisão
   ↓
Consequência
   ↓
Nova Situação
```
